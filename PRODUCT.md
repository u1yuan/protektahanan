# Protektahanan

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Filipino older adults checking suspicious messages and call descriptions. Understand warning signs, independently verify, and optionally prepare a report. No authenticity or safety guarantee.

## Capabilities and constraints
React + Vite + TypeScript. Guided input, assessment, report preparation. Filipino and English, 20px text, 48px targets, keyboard access. Transient input only. No suspicious URL fetching.

Latest user instruction: no API access; make the app work immediately. Clearly disclosed reference mode is the default. Gemini remains optional. Reference checks are not live AI or machine learning. Real AI and public deployment verification require external access.
